# snake

多人在线、多房间的贪吃蛇游戏：Go 后端 + 浏览器前端。

## 运行

```sh
./build.sh   # 生成 .webcool-go-app 与 build/snake
./run.sh     # 启动服务
```

服务监听 `127.0.0.1:${WEBCOOL_HTTP_PORT:-18080}`，用浏览器打开该地址即可开始游戏。

## 玩法

- 填写昵称与房间名加入房间，也可以点击“在线房间”列表直接切换房间；
- 食物数量用拉杆在线调节（1–20），对当前房间内所有玩家立即生效；
- 速度分为慢 / 中 / 快三档，每个玩家独立切换；
- 空格键暂停或继续；蛇撞墙死亡后按空格键重新开始；
- 方向键或 WASD 控制方向。
