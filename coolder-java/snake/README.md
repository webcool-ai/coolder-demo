# 🐍 多人多房间在线贪吃蛇

Go 标准库实现的后端（自带 WebSocket，零第三方依赖）+ 浏览器 Canvas 前端。

## 运行

```bash
go build -o snakeserver ./src
./snakeserver -addr :8080
# 浏览器打开 http://localhost:8080
```

## 玩法

- 输入昵称与房间名加入；不同房间互不干扰，同房间玩家实时同屏对战（每房最多 8 人）
- 方向键 / WASD 移动；手机上滑动棋盘改变方向
- **空格**：按一次暂停，再按继续；**死亡后按空格重新开始**
- 撞墙（或撞到蛇身）即死亡，尸体保留显示，不参与碰撞
- 工具栏**滑杆**：左右拖动实时增减房间食物数量（1–50，全房间生效、渐进过渡）
- **速度三档**：慢速（300ms/帧）、中速（160ms/帧）、快速（90ms/帧），全房间即时切换
- 大厅自动展示活跃房间（`GET /api/rooms`）

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/ws.go` | RFC6455 最小 WebSocket 服务端实现（握手/掩码/分帧/ping-pong/close） |
| `src/game.go` | 纯游戏逻辑：网格、蛇、食物、三档速度、两阶段碰撞判定、滑杆目标渐进生效 |
| `src/room.go` | 房间管理器、每房间 goroutine 主循环、命令邮箱、JSON 协议、每帧快照广播 |
| `src/main.go` | HTTP 入口：`/ws`、`/api/rooms`、`go:embed` 内嵌静态资源 |
| `src/static/*` | 大厅 + 游戏界面（Canvas 渲染、排行榜、事件动态、暂停/死亡覆盖层） |
| `src/main_test.go` | 核心规则单元测试（速度/食物目标/撞墙/复活/暂停/转向/迎头相撞） |

## 并发模型

- 每个房间一个 goroutine：`select { 命令邮箱 | ticker }`，每帧先排空邮箱再推进世界并广播
- 玩家读写各一个 goroutine；写协程定期发 Ping 保活，读超时 2 分钟自动清理
- 房间无人时自动关闭销毁；游戏世界只在房间循环内变更，无锁竞争
